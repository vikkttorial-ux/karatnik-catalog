# По фото и описанию — пилот

В каталоге добавлена отдельная страница smart-search.html. Обычный поиск сохранён.

Фото сравниваются локально на устройстве (CLIP ViT-B/32, Xenova, pinned revision 6b7c523703ae26e39be4b03774966f8571c7f523; MIT). Клиентское фото не отправляется на сервер. Первый запуск загружает примерно 110 МБ модели и браузерного модуля; последующие запуски используют доступный кеш браузера. Форма позволяет выбрать одно украшение на фото. Модель возвращает кандидатов по визуальному сходству, не подтверждённый артикул и не происхождение камней.

Фотоиндекс собирается из фотографий текущего открытого каталога и явно заданных ожидаемых поступлений. Не включает закрытую историю продаж и финансовые данные. Метаданные индекса: артикул, марка, путь снимка; количество и наличие берутся только из свежего data.json. Идентичные исходные снимки объединены; выдача предупреждает о нескольких артикулах на одном снимке. Подтверждённый снимок сотрудника заменяет картинку карточки; пока его нет в индексе, старая картинка не используется для визуального поиска этой карточки.

Ежедневный publish.yml строит индекс после успешного чтения источников; эмбеддинги кешируются по SHA снимка + модели + версии предобработки. Модель скачивается из официального репозитория и проверяется по SHA256. Страницы публикуются атомарно после проверок, при сбое остаётся предыдущая публикация. Справочник разбит на части; браузер проверяет SHA частей по манифесту.

Текстовый поиск — ограниченный словарь и правила: тип, металл по явно указанной пробе, проба, цвет, размер, часть плетений и типов серёг, английский/французский замок, подтверждённый стиль Cartier, марка, вставки и явно указанное происхождение бриллиантов. Нераспознанные слова показаны пользователю; бюджет не используется. Неизвестные признаки не считаются подтверждением. Точное сравнение юр-кодов удаляет только префикс и ведущие нули; артикулы сохраняют значащие символы.

Проверка первой версии: 50 точных локальных фото — все найдены первыми; для 50 синтетических обрезанных/JPEG вариантов исходная модель в топ-5 в 45 случаях. Это не оценка на клиентских снимках. Следующий этап — отдельный согласованный набор 50 реальных рекламных/клиентских фото и 30 описаний; оценить известный артикул, похожие варианты, отсутствие товара, общие фото и неверные характеристики. Архив рекламы с привязкой к артикулам пока не создан.

Обновление не требует платного API распознавания. Текущие лимиты хостинга и GitHub остаются действующими.

## Обратная связь
Кнопки карточки открывают отдельную форму. Персональный код берётся из существующего сервиса фото; короткая сессия для примеров не открывает другие разделы. Сохранение только по явному согласию, выбранный обрезанный снимок без исходных EXIF и редактируемое описание. Можно оставить только текст, указать правильный артикул или оставить его неизвестным.

Все примеры приватны, отделены от фотографий карточек и Google-таблицы. Управляющий проверяет их по адресу https://karatnik-product-photos.workspace-903713.chatgpt.site/search-feedback-review.html . Подтверждённую ошибочную разметку можно исключить, история и снимок сохраняются. Модель и карточки не меняются от нажатий; обучение — отдельный этап после проверки выборки.

При поиске явного артикула с дефисом не сопоставлять его цифры с юр-кодом другого изделия. Явный «юр-...» — только код; явный «артикул...» — только артикул; голое число допускает оба варианта с соответствующей подписью.
